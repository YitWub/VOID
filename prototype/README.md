# 다시가동 프로토타입 — 구조와 유지보수

## 바로 하는 법

```bash
node build.mjs      # src/ → index.html, index.local.html
node test.mjs       # 회귀 테스트 37개
open index.local.html
```

`src/` 를 고치고 **반드시 `node build.mjs`** 를 돌립니다. `index.html` 은 생성물이라 직접 고치면 다음 빌드에 덮어쓰입니다.

## 파일

| 파일 | 역할 | 고칠 일이 생기는 때 |
|---|---|---|
| `src/index.html` | 화면 뼈대(마크업)만 | 입력 항목·탭을 추가할 때 |
| `src/styles.css` | 전부 | 디자인 |
| `src/lib.js` | 날짜·저장소·escape 유틸 | 거의 없음 |
| **`src/content.js`** | **모든 문구와 법령 근거** | **법이 바뀔 때 — 대부분 여기만** |
| `src/plan.js` | 조건 → 단계·기한 계산 (DOM 없음) | 분기 규칙이 바뀔 때 |
| `src/app.js` | 렌더링·이벤트 | 화면 동작이 바뀔 때 |
| `build.mjs` | 단일 파일로 합침 | 거의 없음 |
| `test.mjs` | 회귀 테스트 | 규칙을 추가할 때 같이 |

산출물 두 개:
- **`index.html`** — 제출·퍼블리시용. `<html>/<head>/<body>` 가 없습니다(아티팩트로 올릴 때 자동으로 감싸짐)
- **`index.local.html`** — 로컬 확인용. 더블클릭으로 열립니다

## 왜 이렇게 나눴나

리팩터링 전에는 382줄 한 파일에 HTML·CSS·JS·법령 문구가 섞여 있었고, **법령 텍스트가 JS 삼항연산자 안에 박혀** 있었습니다. 조문 하나를 고치려면 렌더링 코드를 읽어야 했습니다.

지금은 **법이 바뀌면 `content.js` 의 문자열만** 고치면 됩니다. JS 문법을 몰라도 `title` / `body` / `law` 값은 고칠 수 있습니다.

## 단계 하나를 추가하는 법

`src/content.js` 의 `OWNER_STEPS` 에 객체 하나를 넣습니다.

```js
{ id:'o18',                 // 중복 금지 (test.mjs 가 검사)
  phase:7,                  // 0 | 1 | 7 | 30 | 'tax' | 'none'
  tag:'warn',               // 'must' | 'warn' | 없음 → 화면 배지
  kind:'right',             // duty | right | contract | advice (§5 분류, 화면에는 안 나감)
  when:(c)=>c.rent,         // 생략하면 항상 표시
  title:'...',
  law:'근거 조문',           // duty·contract 는 필수 (test.mjs 가 검사)
  body:(c)=>c.corp ? '...' : '...',
  where:'...', due:'...' }
```

`body`·`title`·`where`·`due`·`tag`·`law` 는 **문자열이거나 `(조건)=>문자열`** 입니다.

### 조건 플래그 (`content.js` 의 `context()`)
`hurt` 부상자 있음 · `insured` 보험 가입 · `insUnknown` 가입 여부 모름 · `corp` 법인 · `rent` 임차 · `gov24` 정부24 온라인 발급 대상(개인 AND 자가) · `small` 50인 미만

새 분기를 만들면 **반드시 `context()` 에 이름을 붙이고** 쓰세요. 인라인 삼항을 늘리지 않는 것이 이 구조의 핵심입니다.

### 기한 묶음 (`PHASES`)
`0/1/7/30` 은 화재일 + N일. `'tax'` 는 사업자 유형에 따라 30 또는 90. **`'none'` 은 화재일로 셀 수 없는 기한** — 국세 납부기한 연장이 여기 들어갑니다. D+N 으로 표시하면 틀린 날짜가 화면에 뜹니다.

## 문구를 고칠 때 지킬 것

`docs/legal-basis.md` 와 `CLAUDE.md §8` 에서 온 규칙입니다. `test.mjs` 가 일부를 자동으로 막습니다.

- 조문 번호·금액·기한을 임의로 바꾸지 않기
- 조건부 제도에는 **"시 인정 시"** 를 붙이기 (재해 정책자금, 지방세 연장)
- **감식 전 철거**(위법·벌금)와 **손해사정 전 철거**(위법 아님·실무 불이익)를 섞지 않기
- 임대인 배상은 **증명책임이 어디 있는지만** 쓰고 책임 유무를 단정하지 않기
- 보험 **'모름'을 '미가입'으로 단정하지 않기** (상법 657조 통지 의무가 사라짐)
- 재가동 전 전기점검에 `필수` 배지를 붙이지 않기 (법적 의무 아님)
